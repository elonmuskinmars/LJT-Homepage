# Junteng Liu's Academic Website

**This is a personal academic website built with the [Academic Pages template](https://github.com/academicpages/academicpages.github.io) and hosted on GitHub pages.**

GitHub pages is a free service in which websites are built and hosted from code and data stored in a GitHub repository, automatically updating when a new commit is made to the repository.

## About This Website

This website serves as my academic portfolio, showcasing my research work, publications, and academic background. The site is powered by Jekyll and the Academic Pages theme, which provides a clean and professional layout for academic content.

### Site Features

- **Publications**: List of academic papers with citations and venues
- **Profile Page**: Personal information, education, research experience, and contact details
- **Dynamic Content**: All content is data-driven through structured Markdown files

## Getting Started

1. Go to the repository settings (rightmost item in the tabs that start with "Code", should be below "Unwatch").
2. Check status by going to the repository settings, in the "GitHub pages" section under: Settings → Pages → Source: GitHub Actions
3. For local development, run `jekyll serve -l -H localhost` to generate the HTML and serve it from localhost:4000
